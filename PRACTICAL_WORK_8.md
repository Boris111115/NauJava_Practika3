# Практическая работа № 8. Автоматизированное тестирование

В проект добавлены тесты на основе JUnit 5, Mockito, REST Assured и Selenium WebDriver.

## 1. JUnit и Mockito

Класс `PatientTransferServiceImplTest` проверяет сервис передачи пациентов:
- успешное создание передачи;
- отклонение `null` ID, пустого ID пациента и отрицательного времени;
- поиск передачи;
- проверку отрицательного времени при обновлении;
- делегирование удаления и получения списка репозиторию;
- определение задержки (более 10 минут) и граничное значение 10 минут;
- исключение, если передача не найдена.

## 2. REST Assured

Класс `PatientTransferRestControllerTest` проверяет эндпоинты `/custom/patient-transfers`:
- успешный поиск по ID пациента;
- пустой результат поиска;
- успешный поиск по названию больницы;
- HTTP 400 при отсутствии обязательного query-параметра.

Тесты используют REST Assured с MockMvc и Mockito, поэтому не требуют запуска базы данных.

## 3. Selenium WebDriver

Класс `LoginLogoutSeleniumTest` проверяет вход через `/login`, отображение страницы `/patients/view` и выход через кнопку «Выйти».

Selenium-тест отключён по умолчанию, чтобы обычный `mvn test` не требовал установленного браузера и запущенного приложения. Для его запуска:

1. Запустить приложение и убедиться, что оно доступно по адресу `http://localhost:8080`.
2. Убедиться, что существует тестовая учётная запись. По умолчанию в исходной конфигурации администратора заданы `admin` / `ChangeMe123!`; если пароль изменён, передать актуальные значения через переменные окружения.
3. Установить переменные окружения `RUN_SELENIUM=true`, `APP_BASE_URL=http://localhost:8080`, `TEST_USERNAME=admin`, `TEST_PASSWORD=ChangeMe123!`.
4. Выполнить `mvn -Dtest=LoginLogoutSeleniumTest test`.

WebDriverManager автоматически подбирает ChromeDriver. Требуется установленный Google Chrome.

## 4. Запуск

Все обычные тесты: `mvn test`.

Selenium отдельно: `mvn -Dtest=LoginLogoutSeleniumTest test` при установленных переменных окружения и работающем приложении.

Зависимости тестирования добавлены в `pom.xml`. Существующие тесты предыдущей практической работы сохранены.
